Dicas de Lógica que Você Precisa Saber

1. Divida para Conquistar

Quebre problemas complexos em partes menores e mais simples de resolver.

problema_grande = [sub_problema_1, sub_problema_2, sub_problema_3]

2. Pseudocódigo Antes do Código

Escreva a lógica em linguagem natural antes de programar. Economiza tempo.

se (idade >= 18) { vai_pra_faculdade } senão { vai_pra_escola }

3. Trace o Código Manualmente

Execute o código passo a passo no papel para entender o fluxo.

x = 5; y = 3; resultado = x + y // resultado = 8

4. Use Fluxogramas

Visualize decisões e loops com diagramas antes de programar.

[ Início ] → [ Decisão ] → [ Ação ] → [ Fim ]

5. Nomes Descritivos

Use nomes de variáveis que explicam o que armazenam.

idade_usuario (ao invés de: a) | total_vendas (ao invés de: t)

6. Teste Casos Extremos

Sempre teste seu código com valores mínimos, máximos e nulos.

entrada = [0, 1, -1, 999, null, "texto inválido"]
